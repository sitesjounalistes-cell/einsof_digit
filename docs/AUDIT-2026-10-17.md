## Non traités / assumés (documentés)

- `typescript.ignoreBuildErrors: true` conservé : ne peut être retiré sans exécution complète de `tsc` avec les dépendances installées. **À faire avant mise en production** (idem `noImplicitAny: false` dans tsconfig).
- Les 17 commits UUID de l'ancien historique gardent leurs messages (réécriture de messages = risque inutile).
- Le préfixe de cache mixte `einsof-` (SW) vs `eins-` (session storage) : sans impact fonctionnel, harmonisation cosmétique à l'occasion.
- ~27 clés i18n mortes conservées (inoffensives) ; en revanche la divergence fr/en sur `pricing.included` a été supprimée avec les clés mortes ? → Non : les clés `pricing.included/notes` (mortes) sont conservées telles quelles ; la page tarifs utilise `pages-content/tarifs.ts`, identique dans les 5 langues.
- Le fichier tar d'origine (`einsof/einsof`) contient encore la clé révoquée et les fichiers purgés : **ne pas le redistribuer**.
